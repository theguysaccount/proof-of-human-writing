How to show version history in Google Docs and Word

If you wrote your piece in Google Docs or Word, the document may already hold a record of how it grew. Here's how to find it and share it.

Google Docs

  1. Open the document in a browser on a computer.
  2. Click the version history icon (a clock) at the top right, or choose File › Version history › See version history.
  3. Earlier versions are listed on the right, newest first, with times. Expand a group to see the versions inside it.
  4. To share it, give your teacher or editor edit access to the document: version history is shown only to people who can edit it. Or take screenshots of the list and a few versions.

Google's own instructions: Find what's changed in a file.

Microsoft Word

Word keeps version history for files saved to OneDrive or SharePoint in Microsoft 365. Files saved only on your computer don't have it.

  • Windows (Microsoft 365): select the file name in the title bar, then Version history.
  • Mac (Microsoft 365): select the document name in the title bar, then Browse Version History.
  • Word on the web: File › Version History.

Selecting a version opens it so you can compare. With a personal Microsoft account, Word keeps the last 25 versions; work and school accounts depend on how the library is set up. Microsoft's instructions: View previous versions of Office files.

What makes version history convincing

  • Many versions spread over time, not one version holding the finished essay.
  • Early versions that are rough, partial or in a different order.
  • A document that started empty, rather than one that began with the whole text pasted in.

If there's no history

Gather what else you have: notes, outlines, photos of handwritten drafts, browser history of your research, and the times you emailed or uploaded drafts. Offer to talk through how you wrote it. Then, for next time, write somewhere that records the process as you go: Google Docs, Word on OneDrive, or Writing Replay, which records every edit and lets your reader watch it back.

Menu names change as these apps are updated. If a step doesn't match what you see, the help pages linked above are kept current by Google and Microsoft.
